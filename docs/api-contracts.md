# API Contracts — ai-memory

> Generated by BMAD `document-project` (deep scan, 2026-07-28). The server exposes four
> surfaces on one axum app (default port **49374**): **MCP tools** (`/mcp` + stdio), the
> **hook ingress** (`/hook*`), the **admin HTTP API** (`/admin/*`), and the **web + JSON API**
> (`/web`, `/api/v1`, `/workstream/*`). For the third-party JSON API contract in depth, see the
> hand-authored [`frontend-api.md`](./frontend-api.md).

## 1. MCP tools (`ai-memory-mcp`)

**SDK:** `rmcp` (pinned protocol version). **Transports:** stdio *and* streamable HTTP.
**Identity:** stdio ⇒ anonymous actor; HTTP ⇒ `ActorContext` from auth middleware.
**16 `memory_*` tools** on `AiMemoryServer` (`#[tool_router]`):

| Tool | Purpose |
|---|---|
| `memory_query` | Search the wiki (FTS5 + graph-neighbor RRF + optional vector RRF); unions `_global` scope |
| `memory_recent` | Recent activity for the scope |
| `memory_briefing` | Bounded "where we are" briefing snapshot |
| `memory_status` | Server + provider health status |
| `memory_explore` | Guided exploration prompt over the wiki (uses embedded system prompt) |
| `memory_read_page` | Read a page by path |
| `memory_write_page` | Write/version a durable page (`scope: "global"` targets `_global`) |
| `memory_delete_page` | Delete a page |
| `memory_handoff_begin` | Open a cross-agent handoff |
| `memory_handoff_accept` | Accept a handoff (recovery path for agents that ignore SessionStart stdout) |
| `memory_handoff_cancel` | Cancel a handoff |
| `memory_consolidate` | Consolidate a session into wiki pages (LLM) |
| `memory_forget_sweep` | Run the decay eviction sweep |
| `memory_lint` | Lint the wiki (dangling links, rule-migration suggestions) |
| `memory_auto_improve` | Run the auto-improve review |
| `memory_install_self_routing` | Install CLAUDE.md/AGENTS.md routing marker block |

**Notes:** The server does **not** expose MCP resources or MCP prompts (`list_tools` is
customized; `explore_system.md` is internal to `memory_explore`). A `?flavor=moonshot`
query rewrites the tool list to strip root-level `anyOf`/`oneOf`/`allOf` for Kimi/Moonshot
clients that 400 on them (runtime validation still enforces contracts). Page-read
reinforcement writes are throttled to once/minute/page (`ACCESS_BUMP_COOLDOWN`).

## 2. Hook ingress (`ai-memory-hooks`)

HTTP-only. Vendored client hook scripts spool events locally and drain fire-and-forget so the
agent never blocks.

| Route | Method | Purpose |
|---|---|---|
| `/hook` | POST | Single lifecycle event → sanitized observation (returns 202; 429 when in-flight limit saturated) |
| `/hook/batch` | POST | Batched drain of spooled events (the primary path) |
| `/handoff` | GET | Fetch-and-accept a cross-agent handoff snapshot |
| `/workstream/*` | POST/GET | Managed-run ingress (prepare / heartbeat / cancel / context / link / finish / event search) — authenticated |

**Hook event vocabulary** (`HookEvent`): `SessionStart`, `UserPrompt`, `PreToolUse`,
`PostToolUse`, `PreCompact`, `PostCompaction`, `Notification`, `Stop`, `SessionEnd`,
`SubagentStart`, `SubagentStop`, plus `Other` (extensible via `?extension=`/`?source_event=`).
Agent identified via `?agent=claude-code|codex|cursor|…`. `SessionEnd` triggers session-page
synthesis (rule-based, or LLM consolidation when a provider is configured). `Stop` can capture
a sanitized assistant excerpt (double opt-in). Idempotency via `ingest_key` (minted at spool,
resent verbatim on retry).

**Guarantees / bounds:** typed privacy boundary (no observation persists without `Sanitized`);
fast-return but writer-ack awaited so indexes commit with data; in-flight semaphore, per-source
rate limiter, bounded project cache, subagent-session cap — all sized to protect the single
writer under tool-heavy fan-out.

## 3. Admin HTTP API (`ai-memory-mcp::admin`)

~30 plain-HTTP `/admin/*` routes for state-touching CLI operations that don't belong on the MCP
tool surface. The CLI (`ai-memory <subcommand>`) is a thin client of these. Categories:

- **Backup / restore:** backup (tarball), restore.
- **Wiki ops:** page read / write / delete, `restore-page`, checkpoints, git commit.
- **Project / workspace:** CRUD, rename, move, purge, reorg.
- **Maintenance:** bootstrap, lint, curator, forget-sweep, embed backfill, reindex.
- **Auto-improve:** run, report, pending-writes (list/show/diff/approve/reject).
- **Sessions:** `open-sessions` (for `finalize-session`), finalize.

**Auth:** four `AuthLevel` rungs — Anonymous / User / Root — via bearer/basic/cookie, with
constant-time token compare and MCP-spec `WWW-Authenticate` challenges. Root-only routes gate
operational actions.

## 4. Web browser + JSON API (`ai-memory-web`)

Mounted at `/web` (and `/api/v1`). **Read-only** in v1 (no write/agent routes). Registered
*before* the bearer-auth layer; CORS scoped to `/api/v1` only.

### Server-rendered pages (relative to injected `<base href>`)
| Route | Purpose |
|---|---|
| `GET /` | Project list (cards) — the "projects home" |
| `GET /w/{workspace}/{project}` | Page tree + recent activity |
| `GET /w/{workspace}/{project}/p/{*path}` | Rendered markdown + metadata |
| `GET /search?q=…` | FTS5 hit list |
| `GET /static/tailwind.css`, `GET /static/logo.png` | Assets |
| `GET /favicon.ico` | Served at absolute host root (outside base-path/`/web`) |

### JSON API (`/api/v1`) — for third-party frontends
| Route | Purpose |
|---|---|
| `GET /workspaces` | List workspaces |
| `GET /projects` | List projects |
| `GET /workspaces/{ws}/projects/{proj}/pages` | List pages |
| `GET .../pages/{*path}` | Page content (ETag + `If-None-Match` → 304) |
| `GET\|POST /search` | Scoped / global FTS5 (semantic search deferred here) |
| `GET .../recent` | Recent activity |
| `GET .../briefing` | Briefing snapshot |
| `GET /workspaces/{ws}/overview`, `.../projects/{proj}/overview` | Overviews |
| `GET /graph` | Cross-project dependency edges |

All JSON responses carry ETag / Cache-Control. Full contract: [`frontend-api.md`](./frontend-api.md).

## Auth model (all HTTP surfaces)

Static **bearer token** (generate with `ai-memory generate-auth-token`), plus basic/cookie for
the browser. Required for any non-loopback bind, together with `AI_MEMORY_ALLOWED_HOSTS`. This
is a deliberate homelab-scope deviation from full OAuth 2.1, wire-compatible with the MCP
`Authorization: Bearer` shape. Multi-user mode attributes writes to the authenticated actor.
See [`users.md`](./users.md) and [`auto-scope.md`](./auto-scope.md).
