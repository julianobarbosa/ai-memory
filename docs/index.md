## Project Overview

- **Type:** Monorepo — single Rust Cargo workspace (10 crates + `evals` harness)
- **Primary language:** Rust (edition 2024, toolchain **1.95**)
- **Shipped artifact:** one binary, `ai-memory` (from `crates/ai-memory-cli`)
- **What it is:** long-term memory for AI coding agents — sanitized lifecycle capture →
  git-versioned markdown wiki → handoffs + FTS5/vector search back to the next agent
- **Version:** 1.19.1 · **License:** MIT · **Upstream:** github.com/akitaonrails/ai-memory
- **Default port:** 49374 · **Zero-LLM by default**

## Quick Reference

- **Architecture pattern:** single long-running server (axum) over two lockstep sources of
  truth — markdown wiki (git) + SQLite index; CLI is a thin HTTP client.
- **Entry point:** `crates/ai-memory-cli/src/main.rs` → `ai-memory` binary; server via
  `ai-memory serve`.
- **Storage:** SQLite (single-writer actor, 35 migrations, FTS5 + embeddings blob) — no external
  vector DB.
- **Tech stack:** Rust 2024 · rusqlite/refinery · git2 · axum/tower · rmcp (MCP) · reqwest
  (LLM clients) · askama/pulldown-cmark/Tailwind (web) · clap/figment (CLI).

## Getting Started

1. Build & run the server (see [development-guide.md](./development-guide.md)):
   ```bash
   TAILWIND_SKIP=1 cargo run -p ai-memory-cli -- serve --transport http --bind 127.0.0.1:49374 --enable-web
   ```
2. Register an agent: `ai-memory install-mcp --client <c> --apply` (+ `install-hooks --agent <a> --apply`).
3. Browse the wiki at `http://127.0.0.1:49374/web`.
4. For a codebase tour, start with [architecture.md](./architecture.md) →
   [source-tree-analysis.md](./source-tree-analysis.md).
